# Exercise stubs

Copy the stub you are working on into the package, implement it, and run the
matching `labcheck` step. The repository ships a tested reference implementation
so CI and the measured results stay reproducible; do not edit the committed
reference while working — use a branch.

- `ex2_perception_stub.py` → implement `detect_cubes` in
  `src/isaac_starter_lab/perception.py`.
- `ex3_loop_stub.py` → implement the publish/subscribe episode loop in
  `src/isaac_starter_lab/episode.py` (or your own script that produces the same
  artifacts).

Reference solutions are in `solutions/`, with a warning not to open them before
finishing the exercise.
